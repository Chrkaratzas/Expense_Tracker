EXPENSE TRACKER 

THIS APP SOLVES THE PROBLEM OF KEEPING IN TOUCH WITH YOUR EXPENSES AND MAKING CORRECT ECONOMIC DECISIONS
THIS APP IS ABOUT EVERY PERSON THAT WANTS TO ORGANIZE THEIR ECONOMIC BEHAVIOR 

THIS PROGRAM HAS 3 FEATURES, THE USER CAN:
1) ADD AN ITEM HE BOUGHT WITH THE ITEM'S PRICE
2) SEE ALL THE ITEM'S WITH THEIR PRICES
3) SEE THE TOTAL COST OF HIS EXPENSES
THE DATA ARE STORED IN A TEXT FILE AND THEY ARE NOT LOST WHEN THE PROGRAM IS TERMINATED

THE TECHNOLOGY USED IS PYTHON PROGRAMMING LANGUAGE, 3.11.9 VERSION

YOU CAN INSTALL THE SOURCE CODE AND THE TEXT FILE, MAKE SURE YOU HAVE A MODERN PYTHON VERSION FIRST AND PUT THE TEXT FILE AND THE CODE FILE INSIDE THE SAME FOLDER
YOU CAN EITHER CREATE A PROJECT IN AN IDE AND PUT THE FILES IN THE OR RUN TO YOUR TERMINAL: python3 expensetracker.py
